Props: `{ tools: ToolData[], benchmarks: (BenchmarkEntry | null)[] }` where the arrays are parallel (same index = same tool).

The table renders as a CSS grid where column 0 is the row label and columns 1-N are the tool columns. Use inline styles with `var(--*)` tokens (same pattern as all other components).

Rows to display:
1. **Tool header row**: Tool name + vendor
2. **Priority**: Show "Essential" or "Supplementary"
3. **Arena ELO**: `benchmark.arena.eloRating ?? 'N/A'` with rank ordinal
4. **Quality Index**: `benchmark.artificialAnalysis.qualityIndex ?? 'N/A'` + "/100"
5. **Speed (TTFT)**: `benchmark.artificialAnalysis.speedTTFT ?? 'N/A'` + "ms"
6. **API Price**: `benchmark.artificialAnalysis.pricePerMTok` formatted as "$X/MTok" or "N/A"
7. **Free Tier**: "Yes" (green text) or "No" (muted text)
8. **Starting Price**: `benchmark.pricing.startingPrice ?? 'Free'`
9. **Capability count**: `supported/total capabilities`
10. **Each of the 11 capability categories**: Show checkmark (accent color) if supported, dash (muted) if not

Styling: Alternating row backgrounds (`var(--bg-card)` and `var(--bg-alt)`), `var(--border)` between rows, `var(--radius)` on outer container. Row label column uses `fontWeight: 600`, data columns use `fontWeight: 400`. Font size `0.8125rem`.
