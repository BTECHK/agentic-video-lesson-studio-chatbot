Create `content/mappings/scene-content-map.ts` per D-08:

Define `ContentSceneMapping` interface: `{ contentType: 'tool-capability' | 'tool-meta' | 'source', contentPath: string, affectedSceneTypes: SceneType[], reason: string }`.

Define `CONTENT_SCENE_MAPPINGS` const array mapping content nodes to scene types:
- Tool capability data ("capabilities.*") -> ["capability-table", "feature-grid", "comparison-chats", "tool-card-reveal"]
- Tool meta ("name", "description") -> ["tool-card-reveal", "comparison-chats", "capability-table"]
- "capabilities.writing-chat" -> ["comparison-chats"] (chat comparison scenes)
- "capabilities.dictation" -> ["voice-demo"]
- Any capability -> ["setup-checklist"]

Export `getAffectedScenes(toolId: string, changedPaths: string[]): SceneType[]` — matches changed paths against mappings using prefix matching, returns deduplicated scene types.

Export `getToolsAffectingScene(sceneType: SceneType): string[]` — reverse lookup returning contentPath values where affectedSceneTypes includes the given sceneType.
