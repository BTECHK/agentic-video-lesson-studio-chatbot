<objective>
Define all Zod schemas that validate the content repository: tool capability files, source bibliography files, lesson content JSON, and scene type content shapes.

Purpose: These schemas are the contract layer. Every content file (tool data, sources, lessons) is validated against them. They enforce D-03 (fixed capability enum), D-01 (tool file structure), D-05 (source bibliography structure), and the locked design system schemas from 05-content-schema.md and 03-scene-catalog.md. Without validated schemas, content data has no structural guarantee.

Output: 6 TypeScript schema files in content/schemas/ plus comprehensive unit tests.
</objective>

- `CoverContentSchema`: eyebrow (string), title (array of strings), sub (string), stats (optional array of { id, value: number, suffix?: string, label })
- `JourneyMapContentSchema`: eyebrow, title, sub, stops (array of { id, label, title, state: z.enum(["done", "active", "todo"]) })
- `ComparisonChatsContentSchema`: eyebrow, title, caption (optional), prompt, tools (array of { id, name, logo, response }), tether (boolean, optional)
- `ToolCardRevealContentSchema`: eyebrow, title, sub, tools (array of { id, name, logo, tag, oneliner })
- `CapabilityTableContentSchema`: eyebrow, title, footnote (optional), headers (string array), rows (array of { id, label, cells: array of z.enum(["B", "Y", "L", "-"]) })
- `SetupChecklistContentSchema`: eyebrow, title, sub, items (array of { id, name, why, activateAt: number }), cursor (boolean, optional)
- `FeatureGridContentSchema`: eyebrow, title, features (array of { id, n, cat, title, sub, focusAt: number })
- `VoiceDemoContentSchema`: eyebrow, title, sub, transcript, transcriptLabel
- `RecapGridContentSchema`: eyebrow, title, cards (array of { id, n, title, body }), preview (optional object with eyebrow, title)
- `PreviewBandContentSchema`: eyebrow, title
- `DemoCueContentSchema`: eyebrow, title, sub, meta (array of { id, k, v })
- `DigDeeperContentSchema`: z.object({}) (empty — renders as static element per catalog, no own scene)
- `AssignmentListContentSchema`: eyebrow, title, sub, tasks (array of { id, bold, context }), callout (optional { label, body })
- `QuoteCardContentSchema`: eyebrow, quote, attribution
- Export `SCENE_TYPES` as the literal array of 13 type strings: `["cover", "journey-map", "comparison-chats", "tool-card-reveal", "capability-table", "setup-checklist", "feature-grid", "voice-demo", "recap-grid", "preview-band", "demo-cue", "dig-deeper", "assignment-list", "quote-card"]`
- Export `SceneTypeSchema` as z.enum of SCENE_TYPES
- Export `SceneContentSchema` as a function or discriminated union that maps scene type string to its content schema (use z.discriminatedUnion on a wrapper, or export a `getContentSchema(type: SceneType)` lookup function)

Create `content/schemas/lesson.ts` per 05-content-schema.md:
- Define `LessonMetaSchema`: createdAt (string), lastUpdated (string), authors (string array), factCheckedAt (string or null)
- Define `LessonInfoSchema`: title (string), topic (string), module (string), duration (number), brandLabel (string, optional, default "Sample Academy")
- Define `SceneBaseSchema`: id (string), type (SceneTypeSchema from scene-types.ts), start (number), duration (number), label (string, optional), content (z.record(z.string(), z.unknown()) as base — refined per type via superRefine or pipe)
- Define `LessonSchema`: schemaVersion (z.literal("1.0")), id (string), lesson (LessonInfoSchema), scenes (array of SceneBaseSchema, min 1), speakerNotes (optional string array), meta (LessonMetaSchema)
- Add a `.superRefine()` on LessonSchema that checks timing constraints: scenes[0].start === 0, adjacent scenes have no gaps (scenes[i+1].start === scenes[i].start + scenes[i].duration), lesson.duration === last scene start + last scene duration
- Export schemas and types: `Lesson`, `SceneBase`, `LessonMeta`, `LessonInfo`
