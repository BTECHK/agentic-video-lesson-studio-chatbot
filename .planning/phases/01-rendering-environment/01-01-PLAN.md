  <files>

  <read_first>

  </read_first>
  <action>
    1. Create `docker/Dockerfile.render` per D-03 and D-08. Base image: `node:22-bookworm-slim`.
       ```dockerfile
       FROM node:22-bookworm-slim

       # Chrome dependencies + FFmpeg + fontconfig (per INFRA-01, INFRA-03)
       RUN apt-get update && apt-get install -y --no-install-recommends \
         libnss3 libdbus-1-3 libatk1.0-0 libgbm-dev libasound2 \
         libxrandr2 libxkbcommon-dev libxfixes3 libxcomposite1 \
         libxdamage1 libatk-bridge2.0-0 libpango-1.0-0 libcairo2 \
         libcups2 ffmpeg fontconfig \
         && rm -rf /var/lib/apt/lists/*

       # Bundle Syne font per D-08 (no network dependency at render time)
       COPY public/fonts/*.ttf /usr/share/fonts/syne/
       RUN fc-cache -fv

       # Non-root user for security
       RUN useradd -m -u 1000 remotion
       WORKDIR /app

       COPY package*.json ./
       RUN npm ci

       # Install Chrome Headless Shell for Remotion
       RUN npx remotion browser ensure

       COPY . .
       RUN mkdir -p output/video output/verification/screenshots output/validation
       RUN chown -R remotion:remotion /app

       USER remotion
       CMD ["npx", "remotion", "render", "src/index.ts", "BrandShowcase", "--output", "output/video/brand-showcase.mp4"]
       ```

    2. Create `docker/Dockerfile.dev` per D-02. Same base but runs Remotion Studio:
       ```dockerfile
       FROM node:22-bookworm-slim

       # Chrome dependencies + fontconfig (same as render for consistency)
       RUN apt-get update && apt-get install -y --no-install-recommends \
         libnss3 libdbus-1-3 libatk1.0-0 libgbm-dev libasound2 \
         libxrandr2 libxkbcommon-dev libxfixes3 libxcomposite1 \
         libxdamage1 libatk-bridge2.0-0 libpango-1.0-0 libcairo2 \
         libcups2 fontconfig \
         && rm -rf /var/lib/apt/lists/*

       # Bundle Syne font per D-08
       COPY public/fonts/*.ttf /usr/share/fonts/syne/
       RUN fc-cache -fv

       RUN useradd -m -u 1000 remotion
       WORKDIR /app

       COPY package*.json ./
       RUN npm ci
       RUN npx remotion browser ensure

       COPY . .
       RUN chown -R remotion:remotion /app

       USER remotion
       # Remotion Studio per D-02: hot reload, timeline scrubbing, composition selection
       CMD ["npx", "remotion", "studio", "--port", "3000"]
       ```

    3. Create `docker-compose.yml` per D-03 with two services:
       ```yaml
       services:
         dev:
           build:
             context: .
             dockerfile: docker/Dockerfile.dev
           ports:
             - "3000:3000"
           volumes:
             - ./src:/app/src
             - ./public:/app/public
           environment:
             - NODE_ENV=development

         render:
           build:
             context: .
             dockerfile: docker/Dockerfile.render
           volumes:
             - ./output:/app/output
           shm_size: '2gb'
           environment:
             - NODE_ENV=production
       ```

    4. Create `.dockerignore`:
       ```
       node_modules
       output
       .git
       .planning
       *.md
       test/fixtures
       ```

    IMPORTANT: Do NOT mount node_modules as a volume (anti-pattern from RESEARCH.md -- Chrome Headless Shell lives inside node_modules and would be lost).
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host to Docker container | Source code and fonts copied into container at build time |
| Docker container to filesystem | Output volume mount allows container to write to host output/ directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | Docker container | mitigate | Run as non-root user `remotion` (uid 1000) via `USER remotion` in Dockerfile |
| T-01-02 | Elevation of Privilege | Docker socket | mitigate | Never mount /var/run/docker.sock in render containers -- docker-compose.yml has no socket mount |
| T-01-03 | Tampering | Output volume | accept | Output directory is local development only; no untrusted consumers in Phase 1 |
</threat_model>
