<objective>
Build the post-render validation pipeline using TDD. This script runs automatically after every render (per D-06) and checks file size, resolution, fps, blank frames, font rendering, and duration accuracy.

Purpose: Validation is the automated quality gate per VERI-04 -- no render output is accepted without passing all checks. Building this with TDD ensures each validation check is precise and independently verifiable. The validation logic can be tested against mock/fixture data without requiring a real render.

Output: A tested validation script that produces a JSON report and exits non-zero on failures.
</objective>

<feature>
  <name>Post-Render Validation Pipeline</name>
  <files>scripts/verify.ts, test/validation.test.ts</files>
  <behavior>
    **MP4 Metadata Validation (via ffprobe):**
    - validateFileSize(filePath): returns { passed: true } when file < 1.8GB (1,932,735,283 bytes), { passed: false, value, limit } when >= 1.8GB
    - validateResolution(metadata): returns { passed: true, width: 1920, height: 1080 } for correct resolution, { passed: false } otherwise
    - validateFps(metadata): returns { passed: true, value: 30 } for 30fps, { passed: false } for other values
    - validateDuration(metadata, expectedSeconds): returns { passed: true } when actual duration is within 0.5 seconds of expected, { passed: false, actual, expected } otherwise

    **Screenshot Analysis (via sharp):**
    - detectBlankFrame(screenshotPath): returns true if >98% of pixels are the same color (all-white #FFFFFF or all-black #000000)
    - verifyFontRendering(screenshotPath): returns true if the screenshot contains pixel variation in expected text regions (indicating real font rendering, not a blank area). Analyzes a center-crop region for standard deviation of pixel values > threshold (25).

    **Pipeline:**
    - validateRender(mp4Path, screenshotsDir, expectedDurationSeconds): runs all checks, writes JSON report to output/validation/report.json, returns ValidationResult with overall passed boolean
    - Exit code: 0 if all checks pass, 1 if any check fails

    **Edge cases:**
    - MP4 file does not exist: all checks fail, report says "file not found"
    - Screenshots directory empty: blank frame check passes (no frames to check), font check fails
    - ffprobe not available: throws with clear error message "ffprobe not found -- is FFmpeg installed?"
  </behavior>
  <implementation>
    1. Use `execSync` to run `ffprobe -v quiet -print_format json -show_format -show_streams "{filePath}"` and parse JSON output
    2. Extract: file size from format.size, resolution from streams[0].width/height, fps from streams[0].r_frame_rate (parse "30/1" format), duration from format.duration
    3. Use `sharp` to load PNG screenshots for blank frame detection: get raw pixel buffer, check if >98% of pixels match a single color
    4. Use `sharp` to load PNG for font rendering: crop center region (25% from each edge), compute pixel standard deviation, compare against threshold
    5. Write ValidationResult as JSON to output/validation/report.json
    6. Return ValidationResult with per-check results and overall passed boolean

    For TDD: create small fixture files in test/fixtures/:
    - A 1x1 white PNG for blank frame detection test
    - A 1x1 colored PNG for non-blank frame test
    - Mock ffprobe output as JSON strings for metadata tests
  </implementation>
</feature>

       ```typescript
       export interface CheckResult {
         passed: boolean;
         [key: string]: unknown;
       }

       export interface ValidationResult {
         passed: boolean;
         timestamp: string;
         checks: {
           fileSize: CheckResult;
           resolution: CheckResult;
           fps: CheckResult;
           blankFrames: CheckResult;
           fontRendering: CheckResult;
           duration: CheckResult;
         };
       }
       ```

    2. **Metadata extraction:** `extractMetadata(filePath: string): VideoMetadata`
       - Run `ffprobe -v quiet -print_format json -show_format -show_streams "{filePath}"`
       - Parse: fileSize from `format.size`, width/height from first video stream, fps from `r_frame_rate` (parse "30/1" -> 30), duration from `format.duration`
       - If ffprobe not found: throw Error("ffprobe not found -- is FFmpeg installed?")
       - If file not found: throw Error("File not found: {filePath}")

       - `validateFps(fps: number)`: passed if === 30
       - `validateDuration(actual: number, expected: number)`: passed if Math.abs(actual - expected) <= 0.5
