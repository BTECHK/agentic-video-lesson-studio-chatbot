<objective>
Build the HTML verification gallery, deterministic frame comparison, and full pipeline orchestrator that chains render -> validate -> gallery.

Purpose: The gallery is the primary human review interface per D-04 -- reviewers open a single HTML file to see all scene screenshots. Deterministic comparison per D-09/D-10 catches visual regressions by comparing rendered frames against reference snapshots at 0.1% pixel tolerance. The pipeline script per VERI-04 ensures no output is accepted without passing validation.

Output: Gallery generator, frame comparator, pipeline orchestrator, and a visual verification checkpoint confirming the full pipeline works end-to-end.
</objective>

    ```typescript

    export interface PipelineResult {
      renderCompleted: boolean;
      validationPassed: boolean;
      galleryGenerated: boolean;
      determinismChecked: boolean;
      outputPaths: {
        video: string;
        gallery: string;
        validationReport: string;
      };
    }

    export async function runPipeline(options?: {
      skipDeterminism?: boolean;
      referencesDir?: string;
    }): Promise<PipelineResult> { ... }
    ```

    Pipeline steps (in order, stopping on failure):
    1. **Render:** Call render function from scripts/render.ts. If it throws, set renderCompleted=false and stop.
    2. **Validate:** Call `validateRender('output/video/brand-showcase.mp4', 'output/verification/screenshots', 10)`. If validation.passed is false, generate the gallery (for debugging) but exit with code 1.
    3. **Gallery:** Call `generateGallery(scenes, validationReport, 'output/verification/index.html')`.
    4. **Determinism (optional):** If `options.referencesDir` is provided and exists, call `compareAllFrames('output/verification/screenshots', options.referencesDir)`. Log results but do not block on first run (no references yet).

    Per VERI-04: the pipeline MUST stop and exit non-zero if validation fails. The gallery is still generated on failure (so the reviewer can see what went wrong), but the pipeline is not considered successful.

    CLI entry point: when run directly, execute `runPipeline()` and exit with appropriate code.
    - `npx tsx scripts/pipeline.ts` -- run full pipeline
    - `npx tsx scripts/pipeline.ts --skip-determinism` -- skip reference comparison (for first run)

    Update docker-compose.yml render service CMD to use the pipeline script instead of direct Remotion render:
    ```yaml
    command: npx tsx scripts/pipeline.ts --skip-determinism
    ```
