# Phase 7.1: Home Page + Platform Walkthrough Video

## What We're Building

Two things before pushing the repo public-ready:

### 1. Home Page with Lesson Video

Replace the current bare AccessGate login screen with a proper landing page that includes:
- The existing Module 1 lesson mockup (`original background content/Module 1 Slides.html`) embedded or rendered as a video
- A clear value proposition for Sample Academy
- The existing access gate (demo/student) as a CTA section

The Module 1 Slides.html already exists — use it as-is, don't recreate it.

### 2. Platform Walkthrough Video (60 seconds max)

A Remotion composition showing the live platform in action — "screen recording style":
- Tutor chatbot receiving a question and returning a content-grounded answer
- Content viewer with tool browsing, filtering, and tool detail
- Comparison page with side-by-side tool data and editorial picks
- Smooth transitions between scenes (spring physics, brand-consistent)

This is NOT Phase 10 (stakeholder demo with mock chatbot responses). This is a simpler product walkthrough showing what currently works, rendered as MP4.

60 seconds max. Can be shorter. 30fps, 1080p, brand system throughout.

### 3. Push to Private GitHub

Create `agentic-video-lesson-studio-chatbot` as a private repo on GitHub and push.

## User Direction

- "We've already created the first lesson video mock up so let's just use that" — no recreation
- "Screen recording style" for the walkthrough — mockups/screenshots of actual platform UI animated in sequence
- "60 seconds max. It can be shorter but no longer than one minute"

## Technical Approach

**For the walkthrough video:**
The platform walkthrough will be a new Remotion composition (`PlatformWalkthrough`) that renders static mockup frames of each platform section with animated transitions. Since we can't screenshot a running Next.js app from inside Remotion, the approach is:
- Create React components that replicate the key UI states (chatbot mid-conversation, content viewer with filters active, comparison page with 3 tools)
- These are static visual representations, not the live app — just the visual appearance
- Animate between them with spring-physics transitions matching the brand motion contract

**For the home page:**
- Convert page.tsx from bare AccessGate to a landing page layout
- Embed Module 1 Slides.html content via iframe or convert key sections to React components
- Keep the access gate as a prominent CTA section

## Decisions Made

- Use existing Module 1 HTML as-is (don't recreate)
- Screen recording style = static mockup frames animated in Remotion
- 60 seconds max (1800 frames at 30fps)
- Push as private GitHub repo (not public)
