<objective>
Build the diff engine that compares scraped data against existing tool JSON to detect changes (with D-07 best-effort mapping for schema drift), and create tests validating scraped data conforms to existing Zod schemas. Tool file path is configurable via basePath parameter for testability.
</objective>

<threat_model>
| ID | Threat | STRIDE | Severity | Mitigation |
|----|--------|--------|----------|------------|
| T-04-01 | Malicious scraped data written to tool JSON | Tampering | HIGH | ToolSchema.safeParse rejects non-conforming data before write |
</threat_model>

<title>Create diff engine with configurable basePath</title>
<files>scripts/ingest/differ.ts</files>
<read_first>
- content/schemas/tool.ts
- content/tools/chatgpt.json
- scripts/validate-content.ts
</read_first>
<action>
Create `scripts/ingest/differ.ts`:
1. `export interface DiffResult { vendor, toolId, changedFields: string[], hasChanges: boolean, unmappedData: Record<string, unknown> }`
2. `export function getToolFilePath(toolId, basePath?)`: returns path to tool JSON. basePath defaults to `join(import.meta.dirname!, '..', '..', 'content', 'tools')` but is overridable for tests
3. `export function diffToolData(toolId, scrapedData, basePath?)`: reads existing, compares fields with JSON.stringify equality, unknown keys go to unmappedData (D-07)
4. `export function applyDiff(toolId, scrapedData, dryRun, basePath?)`: merges, validates with ToolSchema.safeParse, writes if valid and not dryRun, returns { applied, changedFields, validationErrors? }
</action>
<acceptance_criteria>
- Contains `export interface DiffResult`
- Contains `export function diffToolData(` with `basePath?` parameter
- Contains `export function applyDiff(` with `basePath?` parameter
- Uses `ToolSchema.safeParse()` not `.parse()`
- `unmappedData` captures keys not in existing schema
</acceptance_criteria>
<verify>npx tsx -e "import { diffToolData } from './scripts/ingest/differ'; console.log('ok')"</verify>
</task>
