<task id="04-01-03">
<type>execute</type>
<title>Create config loader with Zod validation and CLI merge</title>
<files>scripts/ingest/config.ts</files>
<read_first>
- content/schemas/tool.ts
- scripts/validate-content.ts
- ingest.config.json
</read_first>
<action>
Create `scripts/ingest/config.ts`:
1. `IngestConfigSchema` (Zod): defaults (concurrency, timeoutMs, retries, delayMs, userAgent, maxLogSizeMB), scheduling (frequency enum daily|weekly, dayOfWeek optional, timeOfDay), vendors (record of VendorConfigSchema: enabled boolean, sources record of SourceScrapeConfigSchema: scrapeMode enum active|reference-only, priority number)
2. Export types via `z.infer<>`
3. `export function loadConfig(overrides?)`: reads ingest.config.json via `readFileSync` + `import.meta.dirname`, validates with `safeParse()`, deep-merges overrides
4. `export function parseCliOverrides(args: string[])`: parses `--vendor`, `--concurrency`, `--timeout`, `--dry-run` flags
Use `node:fs`, `node:path` imports.
</action>
<acceptance_criteria>
- Contains `export const IngestConfigSchema = z.object(`
- Contains `export type IngestConfig = z.infer<typeof IngestConfigSchema>`
- Contains `export function loadConfig(`
- Contains `export function parseCliOverrides(`
- Uses `safeParse` not `parse`
</acceptance_criteria>
<verify>npx tsx -e "import { loadConfig } from './scripts/ingest/config'; const c = loadConfig(); console.log(Object.keys(c.vendors).length)"</verify>
</task>
