</objective>

<threat_model>
| ID | Threat | STRIDE | Severity | Mitigation |

<task id="04-04-01">
<type>execute</type>
<title>Create PR workflow with git remote validation</title>
<files>scripts/ingest/pr-workflow.ts</files>
<read_first>
- scripts/verify.ts
- scripts/pipeline.ts
</read_first>
<action>
Create `scripts/ingest/pr-workflow.ts`:
1. `const SHELL_METACHAR_PATTERN = /[;|&$\`]/`
2. `export function sanitizeVendorName(vendor)`: throws if matches metachar pattern
3. `export function checkGitRemote(): { configured: boolean; url?: string }`: runs `git config --get remote.origin.url`, returns { configured: false } if not set, with clear message: "No git remote configured. Run: git remote add origin <your-repo-url>"
4. `export function checkExistingPR(vendor)`: `gh pr list --search "content(${vendor})" --state open --json number --limit 1`, returns true if PR exists
5. `export function createVendorPR(vendor, changedFiles, baseBranch='main', dryRun=false)`: checks remote first (throws with setup instructions if missing), sanitizes vendor, checks existing PR (skips if found), creates branch `content/update-${vendor}-${Date.now()}`, stages+commits, pushes, creates PR via gh, returns { branch, prUrl? }
All execSync with `{ encoding: 'utf-8' }`, wrapped in try/catch.
</action>
<acceptance_criteria>
- Contains `export function checkGitRemote(`
- Contains `export function sanitizeVendorName(`
- Contains `export function createVendorPR(`
- Contains `SHELL_METACHAR_PATTERN`
- checkGitRemote returns `{ configured: false }` when no remote (not throws)
- createVendorPR throws with setup instructions when no remote
</acceptance_criteria>
<verify>npx tsx -e "import { sanitizeVendorName, checkGitRemote } from './scripts/ingest/pr-workflow'; console.log(sanitizeVendorName('anthropic')); console.log(checkGitRemote())"</verify>
</task>
