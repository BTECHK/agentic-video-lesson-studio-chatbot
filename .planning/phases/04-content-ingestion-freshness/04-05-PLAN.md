1. `export interface IngestResult { mode, vendorsProcessed, changesFound, prsCreated, errors, results: Array<{ vendor, status, prUrl? }> }`
2. `export async function runIngest(mode, config, overrides)`: routes by mode:
   - `poll`: all enabled vendors → scrapeVendorSources → extractFromHtml → sanitizeExtracted → diffToolData → applyDiff → createVendorPR if changes
   - `search`: same as poll filtered to --vendor
   - `scheduled`: same as poll, traditional scraper only (NO LLM — Pitfall 6), rotates logs first
   - `schedule-setup`: setupScheduledTask with scheduling config
   - `schedule-remove`: removeScheduledTask
   - `llm-extract`: generate prompts for --vendor via generateExtractionPrompt → writePendingPrompt
3. CLI entry point: `if (require.main === module)` with process.argv parsing, loadConfig, parseCliOverrides
4. Read source files from content/sources/ using readdirSync + JSON.parse for each enabled vendor
</action>

- Contains `export async function runIngest(`
- Contains mode routing for poll, search, scheduled, schedule-setup, schedule-remove, llm-extract
- Contains `if (require.main === module)` entry point
- Scheduled mode does NOT use LLM extraction
- Reads source files from content/sources/
</acceptance_criteria>
