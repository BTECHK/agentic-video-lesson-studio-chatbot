<task id="04-05-02">
<type>execute</type>
<title>Create Dockerfile.ingest and crontab</title>
<files>docker/Dockerfile.ingest, docker/crontab.ingest</files>
<read_first>
- docker/Dockerfile.dev
- docker/Dockerfile.render
- package.json
</read_first>
<action>
1. Create `docker/crontab.ingest`:
   - Default: `0 6 * * 1  cd /app && npx tsx scripts/ingest.ts --mode scheduled >> /var/log/ingest-cron.log 2>&1`
   - Comment header explaining the schedule (Monday 6am UTC) and how to change it
   - Empty trailing newline (required by cron)

2. Create `docker/Dockerfile.ingest`:
   - FROM node:22-bookworm-slim (same base as dev/render)
   - Install cron and git (needed for PR workflow): `apt-get install -y --no-install-recommends cron git`
   - WORKDIR /app
   - COPY package*.json, npm install
   - COPY scripts/ and content/ directories
   - COPY ingest.config.json
   - COPY docker/crontab.ingest /etc/cron.d/ingest-cron
   - RUN chmod 0644 /etc/cron.d/ingest-cron && crontab /etc/cron.d/ingest-cron
   - RUN touch /var/log/ingest-cron.log
   - CMD: use an entrypoint that starts cron daemon AND tails the log (so docker logs works):
     `CMD ["sh", "-c", "cron && tail -f /var/log/ingest-cron.log"]`
   - For one-off runs (not scheduled), override CMD via docker compose run
</action>
<acceptance_criteria>
- docker/Dockerfile.ingest exists and uses node:22-bookworm-slim base
- docker/crontab.ingest exists with weekly schedule
- Dockerfile installs cron and git
- CMD starts cron daemon
</acceptance_criteria>
<verify>test -f docker/Dockerfile.ingest && test -f docker/crontab.ingest && echo "ok"</verify>
</task>

<task id="04-05-03">
<type>execute</type>
<title>Add ingest service to docker-compose.yml and npm scripts</title>
<files>docker-compose.yml, package.json</files>
<read_first>
- docker-compose.yml
- package.json
</read_first>
<action>
1. Add `ingest` service to docker-compose.yml:
   ```yaml
   ingest:
     build:
       context: .
       dockerfile: docker/Dockerfile.ingest
     volumes:
       - ./content:/app/content
       - ./scripts:/app/scripts
       - ./ingest.config.json:/app/ingest.config.json
       - ./logs:/app/logs
     environment:
       - NODE_ENV=production
   ```
   The default CMD runs cron for scheduled polling. One-off commands use `docker compose run`.

2. Add 5 npm scripts to package.json:
   - `"ingest:poll": "docker compose run --rm ingest npx tsx scripts/ingest.ts --mode poll"`
   - `"ingest:search": "docker compose run --rm ingest npx tsx scripts/ingest.ts --mode search"`
   - `"ingest:schedule": "docker compose up -d ingest"`
   - `"ingest:unschedule": "docker compose stop ingest"`
   - `"ingest:llm": "npx tsx scripts/ingest.ts --mode llm-extract"`
   Note: ingest:llm runs on host (needs Claude Code session), all others run in container.

3. Run dry-run smoke test: `npx tsx scripts/ingest.ts --mode search --vendor anthropic --dry-run`
   (Run on host first to verify the script works — Docker build can be validated separately)

4. Run full test suite: `npx vitest run` — all tests green

5. Verify TRAN-01 deferred: no files matching *transcri* in scripts/
</action>
<acceptance_criteria>
- docker-compose.yml contains `ingest` service with Dockerfile.ingest
- package.json contains all 5 ingest:* scripts
- ingest:poll, ingest:search route through docker compose run
- ingest:schedule starts the container (cron daemon)
- ingest:llm runs on host (Claude Code passthrough)
- `npx tsx scripts/ingest.ts --mode search --vendor anthropic --dry-run` exits 0
